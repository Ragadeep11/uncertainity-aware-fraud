Mathematical Framework

1. Conformal Coverage Guarantee

Given holdout calibration scores $s_i = 1 - \hat{P}(Y_i \mid X_i)$, the prediction set is constructed as:

Γα(x) = { y ∈ {0,1} : 1 - P(y|x) ≤ q̂ }

Guarantees P(Y ∈ Γα(X)) ≥ 1 - α in finite samples without distributional assumptions.

2. Epistemic vs. Aleatoric Decomposition

Aleatoric uncertainty measures boundary noise: $U_a = - \sum p \log_2 p$. Epistemic uncertainty measures feature space novelty via distance to training distribution:

Ue(x) = tanh( ||x - μkNN|| / σ95 )
3. Expected Operational Loss Minimization

The optimal action $a^*$ minimizes realized cost:

a* = argmina E[ Cost(a | x, Amount, Evidence) ]
